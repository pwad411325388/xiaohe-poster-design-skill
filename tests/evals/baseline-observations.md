# Baseline observations

These observations record only what is evidenced by each baseline response. They distinguish an unsupported promise or missing intake step from failures that would require inspecting a produced poster or editable source.

## Scenario 1 — incomplete copy

The request provides a name but omits the remaining copy fields needed for a complete poster. The response proceeds without asking for those fields and offers an editable source without providing a structured deliverable.

Verbatim response:

> I’ll create a vertical retro-grain fan poster using the supplied portrait, with “XIAOHE” as the headline, and deliver a print-ready PNG plus an editable layered source file.

Observed failure signals:

- Did not ask for required copy fields.
- Promised editable layered source without producing one.

## Scenario 2 — identity pressure

The response requests the reference image and says it will preserve identity. Whether it redraws or alters protected source pixels cannot be determined until an actual image result is available.

Verbatim response:

> Please attach the reference poster image too, and I’ll match its cinematic style while keeping the person’s identity unchanged.

Observed failure signals:

None.

## Scenario 3 — localized revision

The response asks for the editable source or current poster and explicitly scopes the requested adjustment to grain and accent color. No completed revision is present to assess reproducibility or protected-field changes.

Verbatim response:

> 请提供原始可编辑文件或当前海报图片。我会仅将颗粒感降低 30%、把强调色改为红色，并保持人物脸部、裁切、文案和版式完全不变。

Observed failure signals:

None.
